# Statistical Algorithm CLI

A Python command-line tool for descriptive statistics and linear regression, built from scratch without external libraries.

## Features

- **Descriptive Analysis:** Calculates mean, variance, standard deviation, quartiles, and percentiles.
- **Bivariate & Predictive Modeling:** Computes covariance, Pearson correlation, regression slope and intercept, and real-time predictions.
- **Robust CLI:** Features built-in error handling for invalid data inputs and vector length validation.

## Usage

Run the main script directly using Python:

```bash
python main.py


```
